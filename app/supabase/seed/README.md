مولَّدة آلياً بـ`scripts/import-hadith.mjs` من [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api) — رخصة **Unlicense** (ملكية عامة، بلا مفتاح، بلا حدود استدعاء).

| | |
|---|---|
| المجموعات | الأربعون النووية · صحيح البخاري · صحيح مسلم |
| الكتب | ١٥٥ (كلها بأسماء عربية) |
| الأحاديث | ١٤٬٦٥٠ |
| مترجمة للإندونيسية | ١٤٬٦٠٨ (٩٩٫٧٪) |
| فصل الإسناد عن المتن | ١٠٠٪ |
| الحجم | ~٢٧ ميجابايت |

## التنفيذ

نفّذ الملفات **بالترتيب الرقمي** في Supabase ← SQL Editor:

```
01-collections.sql   ← المجموعات والكتب والأبواب (نفّذه أولاً)
02-hadiths-1.sql
...
11-hadiths-10.sql
```

قُسّمت الأحاديث على ملفات لأن محرر SQL في Supabase له حد لحجم الاستعلام.

## إعادة التوليد

```bash
node scripts/import-hadith.mjs --books=bukhari,muslim --limit=500
node scripts/import-hadith.mjs --all
```

## ⚠️ تحفّظات علمية — تحتاج مراجعة المشرف

1. **فصل الإسناد عن المتن آليّ.** يعتمد على علامات الاقتباس المحيطة بكلام النبي ﷺ في النص المصدر، ثم على علامات لفظية. نجح في ١٠٠٪ من الأحاديث لكنه **ليس تحقيقاً علمياً** — قد يخطئ في الأحاديث الطويلة أو المركّبة.

2. **الدرجات.** البخاري ومسلم أُعطيا `sahih` مباشرةً (بإجماع الأمة على صحة ما فيهما). غيرهما يُشتق من حقل `grades` في المصدر، والافتراضي عند غياب التصريح هو `hasan` — وهو افتراض متحفّظ يجب مراجعته.

3. **مستوى «الباب» مفقود.** المصدر يوفّر مستويين فقط (كتاب ← حديث)، فأُنشئ باب واحد لكل كتاب باسم «الأحاديث». يمكن تقسيمه لاحقاً يدوياً أو من `sunnah.com` عند توفّر المفتاح.

4. **الترجمة الإندونيسية مجهولة المؤلف** (`author: "Unknown"` في المصدر). مصدرها غير موثّق وقد تكون منقولة من ترجمة محمية بحقوق. **يُنصح بالتحقق قبل النشر العام.**

5. **أسماء الكتب معرَّبة من جدول** في `scripts/book-names-ar.json` كُتب من المعرفة المعيارية — يُستحسن أن يراجعه مشرف المادة.
