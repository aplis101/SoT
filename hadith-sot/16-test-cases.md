# 1. المقدمة (INTRODUCTION)

## 1.1 الغرض (Purpose)

تعرّف هذه الوثيقة حالات الاختبار (Test Cases) لجميع ميزات منصة الحديث الشريف التفاعلية. اشتُقّت الحالات من مواصفات متطلبات النظام (SRS) وتدفقات المستخدم (UC-001…UC-013) والخوارزميات المرجعية (ALG-001…ALG-006) لضمان التحقق من كل متطلب وظيفي.

## 1.2 النطاق (Scope)

تغطي حالات الاختبار الميزات التالية (52 حالة اختبار):

- F001: استعراض المكتبة الحديثية الهرمية (UC-002) — 4 TC
- F002: صفحة الحديث الشاملة (UC-003) — 5 TC
- F003: المشغل الصوتي واختيار الصوت الافتراضي (UC-004, UC-005) — 10 TC
- F004: التسجيل والرفع الصوتي (UC-008, UC-009) — 9 TC
- F005: الإعجاب والتفضيل الشخصي (UC-006, UC-007) — 6 TC
- F006: البلاغات صوتية + محتوى (UC-010, UC-011) — 7 TC
- F007: المصادقة والملف الشخصي (UC-001) — 4 TC
- F008: لوحة تحكم المشرف (UC-012, UC-013) — 7 TC

## 1.3 تنسيق حالة الاختبار (Test Case Format)

| Field | Description |
| --- | --- |
| **TC ID** | معرّف حالة الاختبار (بالصيغة: TC-FXXX-NNN) |
| **Related UC** | معرّف حالة الاستخدام من تدفقات المستخدم |
| **Related Feature** | معرّف الميزة من SRS |
| **Test Scenario** | وصف سيناريو الاختبار |
| **Preconditions** | الشروط الواجب تحققها قبل الاختبار |
| **Test Data** | البيانات المستخدمة في الاختبار |
| **Test Steps** | خطوات الاختبار |
| **Expected Result** | النتيجة المتوقعة |
| **Type** | إيجابي / سلبي / استثنائي |
