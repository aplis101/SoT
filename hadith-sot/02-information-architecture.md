## 3. خريطة الموقع (SITE MAP)

### 3.1 شجرة التنقل (Navigation Tree)

* **PAGE-001:** تسجيل الدخول (عام — بدون شريط تنقل)
* **PAGE-002:** المجموعات — الصفحة الرئيسية بعد الدخول (متاحة للزائر أيضاً)
  * **PAGE-003:** كتب المجموعة المختارة
    * **PAGE-004:** أبواب الكتاب المختار
      * **PAGE-005:** صفحة الحديث ← المحتوى + المشغل + كل التفاعلات
* **PAGE-006:** الملف الشخصي (موثّق فقط)
* **PAGE-007:** لوحة المشرف (admin فقط)
  * **PAGE-007-SUB-01:** بلاغات الصوت
  * **PAGE-007-SUB-02:** بلاغات المحتوى
  * **PAGE-007-SUB-03:** الإعدادات

### 3.2 أنواع التنقل (Navigation Types)

| Navigation | Type | Behavior |
|---|---|---|
| التنقل الهرمي | Breadcrumb | يظهر من PAGE-003 فصاعداً: المجموعة ← الكتاب ← الباب؛ يتيح القفز المباشر لأي مستوى أعلى |
| التنقل العام | Bottom Navigation (جوال) / Top Bar (سطح مكتب) | روابط: الرئيسية (المجموعات)، الملف الشخصي، (لوحة المشرف لمن له صلاحية) |
| لوحة الإجراءات | Bottom Sheet | في صفحة الحديث فقط: السحب للأعلى يفتح قائمة التسجيلات الكاملة |
| النوافذ | Modal / Popup | المسجل، بلاغ المحتوى، معنى الكلمة الغريبة — تفتح فوق الصفحة دون مغادرتها |
| زر الرجوع | Browser Back | يعيد لآخر موضع تصفح محفوظ في الجلسة (SRS F001) |

## 5. تعريفات الصفحات (PAGE DEFINITIONS)

### Page ID: PAGE-001

**Page Name:** تسجيل الدخول

**Purpose:** بوابة الدخول الوحيدة — مصادقة عبر Google OAuth دون أي نماذج كلمات مرور.

**Entry Points:**

* الوصول لأي مسار محمي دون جلسة نشطة (إعادة توجيه تلقائية).
* الوصول المباشر إلى `/login`.

**Exit Points:**

* نجاح الدخول → `/` (PAGE-002).

**Related User Flows:** UC-001

**Child Pages:** None.

**Required Permissions:** عام (زائر). من لديه جلسة نشطة يُعاد توجيهه إلى `/` تلقائياً.

**Notes:** شاشة مينيمالية بهوية المشروع: شعار/اسم المنصة، وصف سطر واحد، زر "المتابعة بحساب Google". لا روابط تسجيل ولا استرجاع كلمة مرور إطلاقاً.

---

### Page ID: PAGE-002

**Page Name:** المجموعات (الرئيسية)

**Purpose:** نقطة الدخول للمكتبة الحديثية — عرض كل المجموعات المتاحة.

**Entry Points:**

* بعد تسجيل الدخول الناجح.
* رابط `/` المباشر (متاح للزائر أيضاً).
* زر "الرئيسية" في شريط التنقل.

**Exit Points:**

* اختيار مجموعة → PAGE-003.
* الملف الشخصي → PAGE-006 (للموثّق).

**Related User Flows:** UC-002

**Child Pages:** PAGE-003.

**Required Permissions:** عام.

**Notes:** كل بطاقة مجموعة تعرض: الاسم العربي، عدد الكتب، وأيقونة دلالية. ترتيب حسب `sort_order`.

---

### Page ID: PAGE-003

**Page Name:** كتب المجموعة

**Purpose:** عرض كتب المجموعة المختارة مع عدّاد الأبواب لكل كتاب.

**Entry Points:** اختيار مجموعة من PAGE-002، أو القفز من Breadcrumb.

**Exit Points:** اختيار كتاب → PAGE-004؛ Breadcrumb → PAGE-002.

**Related User Flows:** UC-002

**Child Pages:** PAGE-004.

**Required Permissions:** عام.

**Notes:** يظهر Breadcrumb ابتداءً من هذه الصفحة: «المجموعات ← [اسم المجموعة]».

---

### Page ID: PAGE-004

**Page Name:** أبواب الكتاب

**Purpose:** عرض أبواب الكتاب المختار مع عدّاد الأحاديث لكل باب.

**Entry Points:** اختيار كتاب من PAGE-003، أو Breadcrumb.

**Exit Points:** اختيار باب → قائمة أحاديث الباب (تُعرض في نفس الصفحة أسفل الأبواب أو كخطوة تالية حسب التصميم — انظر الملاحظة) ← ثم PAGE-005.

**Related User Flows:** UC-002

**Child Pages:** PAGE-005.

**Required Permissions:** عام.

**Notes:** قرار العرض: قائمة الأحاديث تُعرض في نفس الصفحة بعد اختيار الباب (توسعة Accordion) لتقليل مستويات التنقل وتحقيق هدف «≤ 3 نقرات للحديث». كل صف حديث يعرض: الرقم، مقتطف المتن، شارة الدرجة، وعدّاد التسجيلات الصوتية إن وجدت.

---

### Page ID: PAGE-005

**Page Name:** صفحة الحديث

**Purpose:** قلب التطبيق — المحتوى العلمي الكامل + المشغل الصوتي + كل التفاعلات.

**Entry Points:**

* اختيار حديث من PAGE-004.
* رابط مباشر `/hadiths/[hadithId]` (قابل للمشاركة).

**Exit Points:**

* Breadcrumb / رجوع → PAGE-004.
* الملف الشخصي / الرئيسية عبر شريط التنقل.

**Related User Flows:** UC-003, UC-004, UC-005, UC-006, UC-007, UC-008, UC-009, UC-010, UC-011

**Child Pages:**

* PAGE-005-SUB-01: اللوحة المنزلقة للتسجيلات (Bottom Sheet).
* PAGE-005-SUB-02: نافذة التسجيل الصوتي (Modal).
* PAGE-005-SUB-03: نموذج بلاغ خطأ المحتوى (Modal).
* PAGE-005-SUB-04: نافذة معنى الكلمة الغريبة (Popup).

**Required Permissions:** عام للقراءة والاستماع؛ التفاعل (تسجيل/إعجاب/نجمة/بلاغ) يتطلب توثيقاً.

**Notes:** ترتيب الأقسام الثابت (SRS F002): النص (إسناد باهت + متن بارز) ← شارة الدرجة ← الأزرار الإجرائية (تخريج / ⚠️ بلاغ خطأ) ← الترجمة الإندونيسية (LTR معزول) ← الشرح القابل للطي ← المشغل الصوتي السفلي الثابت.

---

### Page ID: PAGE-005-SUB-01

**Page Name:** اللوحة المنزلقة للتسجيلات (Bottom Sheet)

**Purpose:** عرض كل قرّاء الحديث مع الفرز والإجراءات الاجتماعية.

**Entry Points:** السحب للأعلى على شريط «🎙️ N تسجيلات» في المشغل السفلي.

**Exit Points:** السحب للأسفل / زر إغلاق / اختيار تسجيل للتشغيل.

**Related User Flows:** UC-005, UC-006, UC-007, UC-009, UC-010

**Required Permissions:** عرض عام؛ الإجراءات (إعجاب/نجمة/بلاغ/حذف) للموثّقين.

**Notes:** الفلاتر الأربعة الثابتة: الأعلى تقييماً (افتراضي) ← الأكثر استماعاً ← الأحدث ← ⭐ المفضّلة لدي (للموثّق فقط). زر «أضف تسجيلك الصوتي» يقود إلى SUB-02. تفاصيل الصفوف والشارات في `13-ui-component-map.md`.

---

### Page ID: PAGE-005-SUB-02

**Page Name:** نافذة التسجيل الصوتي (Recorder Modal)

**Purpose:** تسجيل تلاوة الطالب من الميكروفون مع المعاينة والضغط والرفع.

**Entry Points:** زر «أضف تسجيلك الصوتي» (SUB-01 أو صفحة الحديث) — بعد اجتياز بوابة الموافقة (أول مرة).

**Exit Points:** نشر ناجح → إغلاق + تحديث القائمة؛ إلغاء → إغلاق دون حفظ.

**Related User Flows:** UC-008

**Required Permissions:** طالب موثّق + `consent_given_at` موثقة + `upload_enabled = true`.

**Notes:** الحالات الداخلية: جاهز ← يسجّل (مؤقّت + حد أقصى) ← معاينة ← يضغط ← يرفع ← نجاح/خطأ. إن وُجد تسجيل سابق: تأكيد الاستبدال (ALG-004) قبل الرفع.

---

### Page ID: PAGE-005-SUB-03

**Page Name:** نموذج بلاغ خطأ المحتوى

**Purpose:** الإبلاغ عن خطأ في النص/الترجمة/الإسناد/التخريج — قناة منفصلة عن بلاغات الصوت.

**Entry Points:** زر «⚠️ الإبلاغ عن خطأ في النص» في صفحة الحديث.

**Exit Points:** إرسال ناجح → إغلاق + رسالة شكر؛ إلغاء → إغلاق.

**Related User Flows:** UC-011

**Required Permissions:** طالب موثّق.

**Notes:** حقول: نوع الخطأ (قائمة مغلقة من enum) + وصف إلزامي ≤1000 حرف. لا عتبات — يصل المشرف فوراً.

### Page ID: PAGE-006

### 7.1 الوحدة: المكتبة الحديثية (M002)

**Level 1 (القوائم الهرمية):**

* بطاقات المجموعات / الكتب / الأبواب (الاسم العربي + العدّاد).
* Breadcrumb ثابت أعلى المحتوى من PAGE-003 فصاعداً.

**Level 2 (قائمة الأحاديث داخل الباب):**

* رقم الحديث + مقتطف المتن (سطران كحد أقصى).
* شارة الدرجة + عدّاد التسجيلات (🎙️ N).

### 7.2 الوحدة: صفحة الحديث (M003/M004/M005)

**Level 1 (المحتوى العلمي الأساسي):**

* الإسناد (باهت) ثم المتن (بارز، خط كبير).
* شارة الدرجة + أزرار: تخريج / ⚠️ بلاغ خطأ.

**Level 2 (المحتوى التفسيري):**

* الترجمة الإندونيسية (قسم مستقل، LTR معزول).
* الشرح الميسر (قسم قابل للطي).

**Level 3 (الصوتيات — ثابت أسفل الشاشة):**

* زر التشغيل الرئيسي + اسم القارئ الافتراضي + شاراته.
* شريط «🎙️ N تسجيلات» القابل للسحب.

### 7.3 الوحدة: لوحة المشرف (M007)

**Level 1:** بطاقات الملخص الأربع (بلاغات صوت / بلاغات محتوى / مخفي تلقائياً / مفتاح الرفع).

**Level 2:** قوائم البلاغات (الأحدث/الأكثر بلاغاً أولاً) مع هوية الأطراف الحقيقية.

**Level 3:** تفاصيل البلاغ الواحد + مشغل التسجيل + أزرار القرار.
