## 1. الغرض والنطاق

تعرّف هذه الوثيقة شاشات وإجراءات لوحة تحكم المشرف (`/admin`) بالتفصيل التنفيذي. اللوحة هي أداة الأستاذ/المعيد الوحيدة للإشراف على المنصة دون كود.

**مبادئ حاكمة:**

1. **كل شيء قابل للتشغيل من الواجهة** — لا حاجة لفتح قاعدة البيانات إلا لترقية مشرف جديد (عملية نادرة موثقة في `06-auth-flow.md`).
2. **الشفافية الكاملة للمشرف:** الهوية الحقيقية والبريد يظهران دائماً (SoT-0 §9-د).
3. **كل إجراء موثق:** منفّذ + وقت (`resolved_by/at`, `verified_by/at`, `updated_by`).

**الوصول:** دور `admin` فقط — حماية مسار (Middleware) + RLS + فحص `is_admin()` داخل كل RPC (دفاع بعمق ثلاثي).

## 2. خريطة الشاشات

```text
/admin (PAGE-007)
├── بطاقات الملخص الأربع (C-091)
├── /admin/reports (PAGE-007-SUB-01) — بلاغات الصوت
│   └── درج تفاصيل البلاغ (C-094) + مشغل + أزرار القرار
├── /admin/content-reports (PAGE-007-SUB-02) — بلاغات المحتوى
│   └── درج تفاصيل بلاغ المحتوى + حالات المعالجة
└── /admin/settings (PAGE-007-SUB-03) — الإعدادات + مفتاح الرفع
```

## 3. PAGE-007: لوحة الملخص (Dashboard)

### بطاقات الملخص (C-091)

| البطاقة | المصدر | الإجراء عند الضغط |
|---|---|---|
| بلاغات صوت مفتوحة | `COUNT(reports WHERE status='open')` | → `/admin/reports` |
| بلاغات محتوى مفتوحة | `COUNT(content_reports WHERE status='open')` | → `/admin/content-reports` |
| تسجيلات مخفية تلقائياً | `COUNT(recordings WHERE is_hidden AND hidden_reason='auto_hidden_threshold')` | → `/admin/reports` بفلتر «مخفي تلقائياً» |
| مفتاح الرفع | `app_settings.upload_enabled` | → `/admin/settings` |

* البطاقة تُضاء بحدود صفراء (amber) عندما يكون عددها > 0 (تنبيه بصري دون إزعاج).
* تحديث تلقائي عند فتح الصفحة (لا Realtime في v1 — T-09).

## 4. PAGE-007-SUB-01: قائمة بلاغات الصوت (`/admin/reports`)

### 4.1 بنية الجدول (C-092)

مصدر البيانات: RPC `admin_list_recordings_queue` (انظر `08-api-contracts.md` §4.2).

| العمود | المحتوى | ملاحظات |
|---|---|---|
| التسجيل | زر تشغيل سريع ▶ + مدة | الاستماع قبل الحكم إلزامي عملياً |
| الحديث | مقتطف المتن + رابط لصفحة الحديث | — |
| صاحب التسجيل | **الاسم الحقيقي + البريد** + اسم العرض | الشفافية الإلزامية |
| البلاغات | العدد الإجمالي + شرائح الأسباب | مرتب تنازلياً افتراضياً |
| الحالة | ظاهر / مخفي تلقائياً / مخفي يدوياً / معتمد ✅ | شارات لونية |
| أقدم بلاغ | التاريخ | فرز ثانوي |
| إجراءات | فتح التفاصيل ← | — |

**فلاتر الشريط العلوي:** الكل / مفتوحة / مخفي تلقائياً / معالَجة. **فرز:** الأكثر بلاغاً (افتراضي) / الأحدث.

### 4.2 درج التفاصيل (C-094)

يُفتح بضغط صف، ينزلق من نهاية الاتجاه (اليسار في RTL):

1. **مشغل التسجيل** كامل (C-107).
2. **معلومات التسجيل:** الحديث (رابط)، صاحبه (حقيقي + بريد + عرض)، العدّادات، حالة الاعتماد/الإخفاء.
3. **قائمة البلاغات على هذا التسجيل:** كل بلاغ (المبلِّغ الحقيقي، السبب، الوصف، التاريخ).
4. **أزرار القرار الأربعة** (RPC `admin_resolve_report`):

| الزر | الإجراء | النوع | التأكيد |
|---|---|---|---|
| إبقاء (رفض البلاغ) | `dismiss` — يغلق البلاغات المفتوحة ويبقي التسجيل | Secondary | بلا تأكيد |
| إخفاء | `hide` — إخفاء يدوي (`hidden_reason='admin_manual'`) | Warning | نعم |
| استرجاع | `restore` — يظهر فقط للمخفي: إلغاء الإخفاء + رفض البلاغات | Secondary | نعم |
| حذف نهائي | `delete_recording` — حذف الصف + الملف | Danger | تأكيد مزدوج + شرح العاقبة |
| اعتماد ✅ | `admin_verify_recording` — زر مستقل بارز | Primary | بلا تأكيد (قابل للعكس) |

### 4.3 سلوك ما بعد القرار

* الصف يتحدث فوراً في الجدول (حالة جديدة).
* Toast: «تم تنفيذ القرار».
* حذف تسجيل = إغلاق كل بلاغاته `resolved` تلقائياً (في نفس المعاملة — sys_uc_012).

## 5. PAGE-007-SUB-02: قائمة بلاغات المحتوى (`/admin/content-reports`)

### 5.1 بنية الجدول (C-093)

| العمود | المحتوى |
|---|---|
| الحديث | مقتطف + رابط |
| نوع الخطأ | شريحة: تشكيل / ترجمة / إسناد / تخريج / أخرى |
| الوصف | نص البلاغ (كامل عند الفتح) |
| المبلِّغ | الاسم الحقيقي + البريد |
| التاريخ | — |
| الحالة | مفتوح / قيد المعالجة / تم الحل / مرفوض |
| إجراءات | تغيير الحالة ← |

### 5.2 سير المعالجة

```text
مفتوح → (المشرف يقرأ ويبدأ التحقق) → قيد المعالجة
      → (تصحيح من مصدر البيانات الخارجي) → تم الحل
      → (بلاغ غير صحيح) → مرفوض
```

**قاعدة إلزامية:** التصحيح الفعلي للنص يتم **من مصدر البيانات الخارجي/سكربت الاستيراد** — لا يوجد محرر نصوص في اللوحة (المحتوى المرجعي قراءة فقط، SRS F001). حالة «تم الحل» تُعنى بعد إصلاح المصدر وإعادة الاستيراد.

## 6. PAGE-007-SUB-03: الإعدادات (`/admin/settings`)

### 6.1 بطاقة مفتاح الرفع (C-097) — أعلى الصفحة

| العنصر | الوصف |
|---|---|
| المفتاح | Toggle كبير: «رفع التسجيلات مفعّل» |
| الحالة المعطّلة | شريط تحذير amber: «الرفع متوقف مؤقتاً — الطلاب يستطيعون الاستماع والتصفح فقط» |
| الأثر | `upload_enabled=false` → تُخفى C-064 والمسجل من كل الواجهات فوراً |

### 6.2 نموذج الإعدادات (C-096)

كل إعداد: عنوان عربي + وصف سطر + حقل إدخال + مجال التحقق (يُرفض فورياً قبل الحفظ):

| الإعداد | الحقل | المجال | الافتراضي |
|---|---|---|---|
| نسبة عتبة التنبيه | رقم عشري | 0 < x ≤ 1 | 0.15 |
| حد التنبيه الأدنى | عدد صحيح | ≥ 1 | 2 |
| نسبة عتبة الإخفاء | رقم عشري | 0 < x ≤ 1 | 0.40 |
| حد الإخفاء الأدنى | عدد صحيح | ≥ 1 | 4 |
| حد لايكات شارة «أفضل تسجيل» | عدد صحيح | ≥ 0 | 3 |
| نافذة الطلاب النشطين (أيام) | عدد صحيح | 1–365 | 30 |
| حد الرفع في الساعة | عدد صحيح | 1–100 | 5 |
| عتبة الاستماع المحتسب (ثوانٍ) | عدد صحيح | 1–60 | 5 |

* زر «حفظ» لكل بطاقة إعداد (أو حفظ مجمع) → RPC `admin_update_setting`.
* يُعرض بجانب كل إعداد: «آخر تعديل بواسطة [المشرف] في [التاريخ]».
* **عرض مساعد حي:** بجانب إعدادات العتبات يظهر: «الطلاب النشطون حالياً: N ← عتبة التنبيه الفعلية: X، عتبة الإخفاء الفعلية: Y» (من `get_active_students_count` + ALG-002) — ليرى المشرف أثر تغييره قبل حفظه.

## 7. الاعتماد ✅ خارج شاشة البلاغات

* في أي قائمة تسجيلات يصلها المشرف (درج البلاغ، صفحة الحديث نفسها عند عرضها كمشرف) يظهر زر الاعتماد/السحب.
* تعدد المعتمدين لحديث واحد مسموح — الافتراضي بينهم: الأحدث اعتماداً ثم الأعلى لايكات (ALG-001).
* سحب الاعتماد فوري وبلا تأكيد (فعل قابل للعكس).

## 8. مصفوفة صلاحيات الإجراءات

| الإجراء | طالب | مشرف | التنفيذ |
|---|---|---|---|
| مشاهدة `/admin` | ❌ 403 | ✅ | Middleware + RLS |
| استماع لتسجيل مبلَّغ | ✅ (الظاهر فقط) | ✅ (بما فيه المخفي) | RLS recordings |
| رؤية الهوية الحقيقية | ❌ | ✅ | `admin_list_recordings_queue` SECURITY DEFINER |
| إبقاء/إخفاء/استرجاع/حذف | ❌ | ✅ | `admin_resolve_report` |
| اعتماد/سحب ✅ | ❌ | ✅ | `admin_verify_recording` |
| معالجة بلاغ محتوى | ❌ | ✅ | `admin_resolve_content_report` |
| مفتاح الرفع + الإعدادات | ❌ | ✅ | `admin_update_setting` |
