# 1. OVERVIEW

## 1.1 Summary

يتنقل المستخدم عبر التسلسل الهرمي الثابت للمكتبة الحديثية: المجموعة ← الكتاب ← الباب ← الحديث، مع عرض عدّادات العناصر في كل مستوى، حتى يصل إلى صفحة الحديث المطلوب.

## 1.2 Goal

يريد المستخدم الوصول إلى أي حديث في المقرر بسرعة عبر الهرمية، خلال 3 نقرات كحد أدنى من الصفحة الرئيسية.

## 1.3 Requirement References

|Requirement ID|Requirement Name|
|---|---|
|F001|استعراض المكتبة الحديثية الهرمية|

## 1.4 Primary Actor

أي مستخدم (زائر/طالب/مشرف)

## 1.5 Supporting Actors

نظام Supabase (PostgREST)

# 2. TRIGGER

المستخدم يفتح الصفحة الرئيسية `/`.

---

# 3. PRECONDITIONS

|ID|Condition|
|---|---|
|PRE-001|محتوى المكتبة الحديثية مستورَد ومتاح في قاعدة البيانات (مجموعات وكتب وأبواب وأحاديث)|

---

# 4. MAIN FLOW

| Step | Actor Action | System Response |
| ---- | ------------ | --------------- |
| 1 | المستخدم يفتح الصفحة الرئيسية `/` | النظام يعرض قائمة المجموعات الحديثية مرتبة (`sort_order`) مع عدد الكتب في كل مجموعة |
| 2 | المستخدم يختار مجموعة | النظام يعرض كتب المجموعة مع عدد الأبواب في كل كتاب |
| 3 | المستخدم يختار كتاباً | النظام يعرض أبواب الكتاب مع عدد الأحاديث في كل باب |
| 4 | المستخدم يختار باباً | النظام يعرض قائمة أحاديث الباب (رقم الحديث + مقتطف من أول المتن + شارة الدرجة) |
| 5 | المستخدم يختار حديثاً | النظام ينقل المستخدم إلى صفحة الحديث `/hadiths/[id]` (انظر UC-003) |

---

# 5. ALTERNATIVE FLOWS

## AF-001: القفز عبر Breadcrumb

### Condition

عند رغبة المستخدم في العودة إلى أي مستوى أعلى في الهرمية مباشرة.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يضغط على أي مستوى في شريط Breadcrumb|النظام ينقله مباشرة إلى ذلك المستوى دون المرور بالمستويات الوسيطة|

---

## AF-002: الرجوع بزر المتصفح/التطبيق

### Condition

عند استخدام المستخدم زر الرجوع (Back) أثناء التصفح.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يضغط زر الرجوع|النظام يعيده إلى آخر موضع تصفح محفوظ في الجلسة نفسها (آخر مستوى وموضع التمرير)|

---

# 6. EXCEPTION FLOWS

## EF-001: مستوى فارغ

### Condition

عند فتح مستوى لا يحتوي عناصر (باب بلا أحاديث مثلاً) لأن المحتوى يُستورَد من مصادر خارجية قد تكتمل لاحقاً.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يفتح مستوى فارغاً|النظام يعرض حالة فارغة واضحة "لا يوجد محتوى بعد"|
|2||النظام لا يُخفي المستوى الفارغ من القائمة الأم|

---

## EF-002: فشل تحميل مستوى

### Condition

عند فشل جلب بيانات مستوى من المستويات (مشكلة شبكة أو خادم).

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يفتح مستوى ويفشل التحميل|النظام يعرض رسالة خطأ مع زر إعادة المحاولة|
|2|المستخدم يضغط زر إعادة المحاولة|النظام يعيد طلب البيانات ويعرض المستوى عند النجاح|

---

# 7. POSTCONDITIONS

|POST-001|المستخدم وصل إلى صفحة الحديث المطلوب خلال 3–4 نقرات كحد أقصى من الصفحة الرئيسية|
|POST-002|آخر موضع تصفح محفوظ في الجلسة لدعم الرجوع (AF-002)|

# 8. BUSINESS RULES

|Rule ID|Description|
|---|---|
|BR-001|التسلسل الهرمي الثابت Collection ← Book ← Chapter ← Hadith لا يُتجاوز: لا يظهر حديث إلا داخل باب، ولا باب إلا داخل كتاب، ولا كتاب إلا داخل مجموعة|
|BR-002|المحتوى في هذه المستويات للقراءة فقط لجميع الأدوار بما فيها المشرف (التعديل يتم من مصدر البيانات الخارجي)|
|BR-003|الوصول إلى الحديث خلال 3 نقرات كحد أدنى من الصفحة الرئيسية|
|BR-004|المستويات الفارغة تُعرض مع مؤشر "فارغ" ولا تُخفى|
