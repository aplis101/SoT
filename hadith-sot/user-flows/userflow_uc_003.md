# 1. OVERVIEW

## 1.1 Summary

يعرض النظام صفحة الحديث الشاملة: النص العربي المشكول بفصل بصري بين الإسناد والمتن، شارة الدرجة، أزرار التخريج والإبلاغ، الترجمة الإندونيسية المعزولة الاتجاه، الشرح الميسر القابل للطي، والغريب التفاعلي، إضافة إلى المشغل الصوتي السفلي.

## 1.2 Goal

يريد المستخدم دراسة الحديث من مكان واحد: قراءة النص المشكول بوضوح، فهم غريب الكلمات، الاطلاع على التخريج والشواهد، وقراءة الترجمة والشرح الميسر.

## 1.3 Requirement References

|Requirement ID|Requirement Name|
|---|---|
|F002|صفحة الحديث الشاملة (نص، ترجمة، غريب، تخريج، شرح)|

## 1.4 Primary Actor

أي مستخدم (زائر/طالب/مشرف)

## 1.5 Supporting Actors

نظام Supabase (PostgREST)

# 2. TRIGGER

المستخدم يختار حديثاً من قائمة الباب (UC-002) أو يفتح رابطاً مباشراً لصفحة حديث `/hadiths/[hadithId]`.

|PRE-002|بيانات الغريب والتخريج والشرح المرتبطة بالحديث مستورَدة (إن توفرت)|

---

# 4. MAIN FLOW

| Step | Actor Action | System Response |
| ---- | ------------ | --------------- |
| 1 | المستخدم يفتح صفحة الحديث | النظام يعرض النص العربي كاملاً مشكولاً: الإسناد بلون رمادي باهت والمتن بارزاً بخط عربي واضح كبير |
| 2 | | النظام يعرض شارة درجة الحديث (صحيح/حسن/ضعيف) بشارة لونية دلالية |
| 3 | | النظام يعرض الأزرار الإجرائية: زر التخريج وزر "⚠️ الإبلاغ عن خطأ في النص" |
| 4 | | النظام يعرض الترجمة الإندونيسية المعتمدة في قسم مستقل باتجاه LTR معزول (bidi isolation) |
| 5 | | النظام يعرض الشرح الميسر والفوائد في قسم قابل للطي |
| 6 | | النظام يُظهر المشغل الصوتي السفلي في أسفل الصفحة (انظر UC-004) |

---

# 5. ALTERNATIVE FLOWS

## AF-001: فتح معنى كلمة غريبة

### Condition

عند ضغط المستخدم على كلمة غريبة مميزة داخل المتن.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يضغط على كلمة غريبة مميزة في المتن|النظام يفتح نافذة منبثقة (Popup) تعرض معنى الكلمة اللغوي|
|2|المستخدم يضغط زر نطق الكلمة (إن توفر `audio_url`)|النظام يشغّل نطق الكلمة صوتياً|

---

## AF-002: عرض التخريج

### Condition

عند رغبة المستخدم في الاطلاع على شواهد الحديث في الكتب الأخرى.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يضغط زر التخريج|النظام يعرض قائمة الشواهد: اسم الكتاب المرجعي ورقم/موضع الحديث فيه|

---

## AF-003: طي/فتح قسم الشرح

### Condition

عند رغبة المستخدم في إخفاء أو إظهار قسم الشرح الميسر.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يضغط على رأس قسم الشرح|النظام يطوي القسم أو يفتحه تبادلياً|

---

## AF-004: الإبلاغ عن خطأ في المحتوى

### Condition

عند ملاحظة المستخدم خطأ في النص أو الترجمة أو الإسناد أو التخريج.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يضغط زر "⚠️ الإبلاغ عن خطأ في النص"|النظام ينقله إلى تدفق الإبلاغ عن خطأ في المحتوى (UC-011)|

---

# 6. EXCEPTION FLOWS

## EF-001: الترجمة أو الشرح غير متوفر

### Condition

عند عدم توفر الترجمة الإندونيسية أو الشرح الميسر لهذا الحديث.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يفتح صفحة حديث بلا ترجمة أو بلا شرح|النظام يُخفي القسم المعني بأناقة دون عرض قسم فارغ|

---

## EF-002: لا توجد كلمات غريبة

### Condition

عند عدم وجود بيانات `word_definitions` مرتبطة بالحديث.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يفتح صفحة حديث بلا بيانات غريب|النظام يعرض المتن دون أي عناصر قابلة للضغط|

---

## EF-003: فشل تحميل نطق الكلمة

### Condition

عند فشل تحميل الملف الصوتي لنطق الكلمة الغريبة.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|فشل تحميل `audio_url` الخاص بالكلمة|النظام يُخفي زر النطق فقط مع بقاء معنى الكلمة ظاهراً في الـ Popup|

---

# 7. POSTCONDITIONS

|ID|Condition|
|---|---|
|POST-001|المستخدم اطّلع على النص المشكول بفصل بصري واضح بين الإسناد والمتن مع كل الأقسام المتاحة للحديث|
|POST-002|لا يُعدَّل أي محتوى (الصفحة قراءة فقط)؛ التفاعلات الوحيدة المؤثرة تنتقل إلى UC-004/UC-011|

---

# 8. BUSINESS RULES

|Rule ID|Description|
|---|---|
|BR-001|الكلمات الغريبة القابلة للضغط محصورة ببيانات `word_definitions` المرتبطة بالحديث فقط — لا يُسمح بأي تمييز نصي آلي خارج هذه البيانات|
|BR-002|الترجمة الإندونيسية وأي أرقام لاتينية داخل الفقرات العربية تُغلَّف بعزل اتجاه (bidi isolation) لمنع قلب الترتيب في النص المختلط|
|BR-003|ترتيب أقسام الصفحة ثابت: النص ← الأزرار الإجرائية (تخريج/بلاغ) ← الترجمة ← الشرح ← المشغل السفلي|
