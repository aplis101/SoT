# 1. OVERVIEW

## 1.1 Summary

يسحب المستخدم شريط "🎙️ N تسجيلات" في المشغل السفلي للأعلى، فتفتح اللوحة المنزلقة (Bottom Sheet) قائمة كل قرّاء الحديث الظاهرين مع الشارات والعدّادات، ويتيح النظام فرزها بأربعة خيارات ثابتة وفلترتها بالمفضّلة الشخصية.

## 1.2 Goal

يريد المستخدم استعراض كل القراءات المتاحة للحديث ومقارنتها (بالشارات واللايكات والاستماعات) واختيار ما يناسبه للاستماع، مع إمكانية الوصول السريع إلى تسجيلاته المفضَّلة.

## 1.3 Requirement References

|Requirement ID|Requirement Name|
|---|---|
|F003|المشغل الصوتي واختيار الصوت الافتراضي|
|F005|الإعجاب والتفضيل الشخصي|

## 1.4 Primary Actor

أي مستخدم (زائر/طالب/مشرف) — فلتر "⭐ المفضّلة لدي" يتطلب مستخدماً موثقاً

## 1.5 Supporting Actors

نظام Supabase (PostgREST)

# 2. TRIGGER

المستخدم يسحب للأعلى على شريط "🎙️ N تسجيلات" في المشغل السفلي بصفحة الحديث.

# 3. PRECONDITIONS

|ID|Condition|
|---|---|
|PRE-001|صفحة الحديث مفتوحة (UC-003)|
|PRE-002|يوجد تسجيل ظاهر واحد على الأقل للحديث (للحالة الفارغة انظر EF-001)|

---

# 4. MAIN FLOW

| Step | Actor Action | System Response |
| ---- | ------------ | --------------- |
| 1 | المستخدم يسحب شريط "🎙️ N تسجيلات" للأعلى | النظام يفتح اللوحة المنزلقة (Bottom Sheet) |
| 2 | | النظام يعرض قائمة كل قرّاء الحديث الظاهرين مرتبة افتراضياً بالأعلى تقييماً |
| 3 | | النظام يعرض في كل صف: اسم العرض، الشارات (✅ معتمد / ⭐ مفضل لدي / أفضل تسجيل)، عدد اللايكات، عدد الاستماعات، المدة |
| 4 | المستخدم يضغط على صف تسجيل | النظام يشغّل ذلك التسجيل مع إغلاق اختياري للوحة |

---

# 5. ALTERNATIVE FLOWS

## AF-001: الفرز بالأكثر استماعاً

### Condition

عند رغبة المستخدم في ترتيب القائمة حسب عدد الاستماعات.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يختار فرز "الأكثر استماعاً"|النظام يعيد ترتيب القائمة حسب `listens_count` تنازلياً|

---

## AF-002: الفرز بالأحدث

### Condition

عند رغبة المستخدم في ترتيب القائمة حسب تاريخ الرفع.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يختار فرز "الأحدث"|النظام يعيد ترتيب القائمة حسب `created_at` تنازلياً|

---

## AF-003: فلتر "⭐ المفضّلة لدي"

### Condition

عند رغبة الطالب الموثق في عرض تسجيلاته المفضَّلة فقط لهذا الحديث.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم الموثق يختار فلتر "⭐ المفضّلة لدي"|النظام يعرض فقط التسجيلات التي فضّلها هذا المستخدم للحديث|
|2||للزائر: الفلتر يُخفى كلياً من خيارات الفرز|

---

## AF-004: فلتر المفضلة فارغ

### Condition

عند اختيار الطالب فلتر "⭐ المفضّلة لدي" دون أن يكون قد فضّل أي تسجيل لهذا الحديث.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يختار فلتر "⭐ المفضّلة لدي" وقائمته فارغة|النظام يعرض رسالة "لم تفضّل أي تسجيل بعد"|

---

# 6. EXCEPTION FLOWS

## EF-001: لا توجد تسجيلات إطلاقاً

### Condition

عند فتح اللوحة لحديث لا يملك أي تسجيل ظاهر.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|المستخدم يفتح اللوحة لحديث بلا تسجيلات|النظام يعرض حالة فارغة واضحة|
|2||للمستخدم الموثق: يعرض النظام زر "أضف تسجيلك الصوتي" (يقود إلى UC-008)|

---

## EF-002: فشل تحميل القائمة

### Condition

عند فشل جلب قائمة التسجيلات من الخادم.

### Flow

|Step|Actor Action|System Response|
|---|---|---|
|1|فشل تحميل قائمة التسجيلات|النظام يعرض رسالة خطأ مع زر إعادة المحاولة|
|2|المستخدم يضغط إعادة المحاولة|النظام يعيد طلب القائمة ويعرضها عند النجاح|

---

# 7. POSTCONDITIONS

|ID|Condition|
|---|---|
|POST-001|المستخدم استعرض القائمة بالفرز/الفلتر المختار وشغّل التسجيل الذي اختاره (إن ضغط صفاً)|
|POST-002|لا يُعدَّل أي بيانات في هذا التدفق — التعديلات تتم عبر UC-006/UC-007 من داخل الصفوف|

# 8. BUSINESS RULES

|Rule ID|Description|
|---|---|
|BR-001|خيارات الفرز الأربعة ثابتة كما في Spec §5-و: الأعلى تقييماً (افتراضي)، الأكثر استماعاً، الأحدث، ⭐ المفضّلة لدي|
|BR-002|التسجيلات المخفية (`is_hidden = true`) لا تظهر في القائمة العامة، وتظهر للمشرف فقط|
|BR-003|زر الحذف يظهر فقط على تسجيلات المستخدم نفسه، وللمشرف على كل التسجيلات (UC-009)|
|BR-004|شارة "أفضل تسجيل" لا تُعرض إلا عند بلوغ `community_best_min_likes` (الافتراضي 3) من `app_settings` (ALG-001 الطبقة 3)|
